# 文档与审查

## 文档规范
-   **SSOT**: 代码即文档。如果代码变更，文档必须同步更新。
-   **Structure**:
    -   `docs/`: 长期维护的设计文档、API 文档。
    -   `openspec/`: 架构变更提案。
    -   `README.md`: 项目入口。

## 会话总结
-   **Path**: `docs/team/YYYY-MM/`
-   **Template**:
    ```markdown
    # Summary - {Topic}
    - **Meta**: {Time} | {Members}
    - **Problem**: {简述问题}
    - **Solution**: {解决方案关键点}
    ```
